# Your Daily Queue

**The news you care about. None of the stuff you don’t.**

Your Daily Queue is a public CapyQueue demo inspired by a real personalized Morning Intelligence Report. It demonstrates what happens when a daily briefing is designed around one person’s interests, attention, and preferred level of detail instead of an infinite feed.

## Demo features

- Fictional reader profile and clearly labeled sample content
- Personalized topic selection
- Quick, balanced, and context-rich reading modes
- Quick Scan and topic-by-topic briefing views
- “More like this” / “Less like this” feedback
- Browser-saved preferences using localStorage
- Responsive mobile layout

## Privacy

This repository contains no personal profile data, private family information, API keys, or live private feeds. All briefing content is fictional demonstration copy.
